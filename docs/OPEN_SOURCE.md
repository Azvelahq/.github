# Open source and public collaboration

Azvela values open technical exchange, reproducible research and responsible contributions to the software ecosystem. Public visibility alone does not grant an open-source license.

Each project determines its publication scope, license, maintenance commitments and contribution process. Respect upstream notices, dependency licenses and third-party intellectual property. Do not publish proprietary code, personal data, restricted research or material that Azvela is not authorized to distribute.

This repository contains public corporate documents and brand assets. No blanket open-source license, trademark license or permission to imply affiliation is granted by this repository. Applicable law and GitHub's terms remain in effect. Obtain permission before reusing material beyond rights already granted by law or an explicit license.

When we publish code under an open-source license, that license will be identified in the relevant repository. Public contributions should be reviewed for security, provenance, maintenance and licensing compatibility.
