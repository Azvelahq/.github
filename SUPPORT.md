# Support

Use the affected project's README and documented support channels first. Public repository issues are intended for actionable technical defects and proposals, not account recovery, billing, personal information or urgent safety issues.

| Need | Route |
| --- | --- |
| Reproducible public software defect | Affected repository's issue tracker |
| Feature or research proposal | Relevant issue template, if available |
| Accessibility barrier | Accessibility template or documented project support |
| Vulnerability | [Security policy](https://github.com/Azvelahq/.github/blob/main/SECURITY.md) |
| Private moderation or security contact not listed | [Contact-only request](https://github.com/Azvelahq/.github/issues/new?template=contact_request.yml) |

For a product without a published support channel, consult the product's official communication when available. Do not post account credentials, private messages, payment details or sensitive screenshots. This repository does not provide a guaranteed support response time or a general-purpose product help desk.
